# Smart Construction Website

Smart Construction is a responsive website designed for a construction and maintenance company. It showcases services, completed projects, and company information with a modern, professional design.

## Features

-   **Home Section**: Engaging landing page with a call to action.
-   **About Us**: Information about the company's experience and quality guarantees.
-   **Services**: Details on offered services like housing construction, repairs, and installations, presented in a slider.
-   **Projects**: Showcase of latest completed projects.
-   **Contact**: Contact information including location, phone numbers, and social media links.
-   **Responsive Design**: Optimized for different screen sizes (mobile, tablet, desktop).
-   **Smooth Animations**: Utilizes ScrollReveal and Swiper.js for a dynamic user experience.

## Technologies Used

-   **HTML5**: Structure of the website.
-   **CSS3**: Styling, including Flexbox and Grid layouts.
-   **JavaScript**: Interactive functionality.
-   **Remix Icon**: Icon library.
-   **Swiper.js**: Touch-enabled mobile touch slider for the services section.
-   **ScrollReveal**: JavaScript library for easy scroll animations.

## Setup and Usage

1.  **Clone or Download**: Download the project files to your local machine.
2.  **Open**: Navigate to the project folder.
3.  **Run**: Open `index.html` in your preferred web browser.

No build step or server is required to view the static site.
